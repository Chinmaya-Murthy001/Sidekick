Sidekick: how one sentence becomes an action

“Let's meet Thursday” → calendars checked → invite sent, before the next person speaks.

1 · Join

Meeting bot

  • Joins Google Meet as “Sidekick”
  • Announces itself in chat
  • Recall.ai bot, or the browser mic in the prototype
→
2 · Listen

Speech to text

  • Streaming transcript
  • Speaker labels mapped to participants
  • One finished utterance at a time
→
3 · Safety check

Pause / resume

  • “Sidekick, stop recording” handled by fixed rules, never the LLM
  • While paused nothing is stored or acted on
→
4 · Decide

Agent (Claude, tool calling)

  • Reads rolling transcript, participants, time, actions so far
  • Decides: act now, or do nothing
thinkcall toolread resultrepeat
Offline fallback: rule-based planner, same tools
→
5 · Act

Tools

  • check_availability
  • schedule_meeting + invite
  • create_task
  • log_decision
  • send_email
  • post_to_meeting_chat
Policy layer (in code, not the prompt)

Guardrails on every tool call

  • Anyone outside the team → held for approval
  • Calendar conflict → no booking, alternatives posted
  • Same action twice → refused as duplicate
  • Agent can't set the approval flag itself
Human in the loop

Host approves in the live feed

  • Approve & send, or Reject
  • Pause / resume by voice
  • Every action shows the words that triggered it
6 · Show

Live activity feed

  • Each action with time and latency
  • Calendar, tasks, decisions, outbox
  • Meeting chat messages
7 · After the call

Summary

  • Decisions, action items with owners and due dates
  • Meetings booked, open questions
  • Emailed to the team
